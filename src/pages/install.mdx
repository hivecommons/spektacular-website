  <InstallMethod heading="Homebrew">

    Install via the official Homebrew tap:

    <InstallBlock command="brew install hivecommons/homebrew-repo/spektacular" full />

  </InstallMethod>

  <InstallMethod heading="Go install">

    If you have Go 1.21+ installed, fetch and build the latest release directly:

    ```bash
    go install github.com/hivecommons/spektacular@latest
    ```

  </InstallMethod>
  
  <InstallMethod heading="Apt (Debian/Ubuntu)">

    If you have Go 1.21+ installed, fetch and build the latest release directly:

    ```bash
    echo "deb [trusted=yes] https://apt.fury.io/jumppad/ /" | \
    sudo tee -a /etc/apt/sources.list.d/fury.list

    sudo apt-get update
    sudo apt-get install spektacular
    ```

  </InstallMethod>

  <InstallMethod heading="Agent skills registry">

    [![Install Spek skills](https://skills.sh/b/hivecommons/spektacular?style=for-the-badge)](https://skills.sh/hivecommons/spektacular)

    Spek's workflow skills are published from the
    [hivecommons/spektacular](https://github.com/hivecommons/spektacular)
    `skills/` catalog so you can install them directly into Claude Code, Bob,
    or Codex without a Hive-managed setup. Install the Spektacular binary first,
    then install the spec skill or the full catalog:

    ```bash
    # Install the spec skill globally for Claude Code, Bob and Codex.
    npx skills add hivecommons/spektacular --skill spek-new -g \
      -a claude-code -a bob -a codex -y

    # Or install every Spek workflow skill.
    npx skills add hivecommons/spektacular --skill '*' -g \
      -a claude-code -a bob -a codex -y
    ```

    Release builds also attach a versioned `spektacular_skills_<VERSION>.tar.gz`
    archive with the same rendered skill catalog. Each skill includes a "Use
    with Hive" section linking standalone users to the Hive integration and the
    [Hive Commons docs](https://docs.hivecommons.dev/).

  </InstallMethod>

  <InstallMethod heading="GitHub Releases">

    Download the latest release archive from
    [GitHub Releases](https://github.com/hivecommons/spektacular/releases),
    extract the binary, and move it to a directory on your `$PATH`. Replace
    `<VERSION>` with the release tag (for example `0.3.0`).

    <ReleaseGrid>

      <ReleaseArtifact label="macOS (Apple Silicon)">

        ```bash
        unzip spektacular_<VERSION>_darwin_arm64.zip
        sudo mv spektacular /usr/local/bin/
        ```

      </ReleaseArtifact>

      <ReleaseArtifact label="macOS (Intel)">

        ```bash
        unzip spektacular_<VERSION>_darwin_x86_64.zip
        sudo mv spektacular /usr/local/bin/
        ```

      </ReleaseArtifact>

      <ReleaseArtifact label="Linux (x86_64)">

        ```bash
        tar -xzf spektacular_<VERSION>_linux_x86_64.tar.gz
        sudo mv spektacular /usr/local/bin/
        ```

      </ReleaseArtifact>

      <ReleaseArtifact label="Linux (ARM64)">

        ```bash
        tar -xzf spektacular_<VERSION>_linux_arm64.tar.gz
        sudo mv spektacular /usr/local/bin/
        ```

      </ReleaseArtifact>

    </ReleaseGrid>

  </InstallMethod>

</InstallMethods>
